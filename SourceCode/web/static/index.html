1. Moore Machine Formal 6-Tuple

M = (Q, Σ, Δ, δ, λ, q₀)

  • Q: Finite set of states
  • Σ: Finite input alphabet
  • Δ: Finite output alphabet
  • δ: Transition function Q × Σ → Q
  • λ: State output function Q → Δ
  • q₀: Initial state in Q

Output Behavior: For input string of length n, the Moore machine produces an output string of length n + 1, emitting λ(q₀) before consuming any input symbol.

2. Mealy Machine Formal 6-Tuple

M = (Q, Σ, Δ, δ, λ', q₀)

  • Q: Finite set of states
  • Σ: Finite input alphabet
  • Δ: Finite output alphabet
  • δ: Transition function Q × Σ → Q
  • λ': Transition output function Q × Σ → Δ
  • q₀: Initial state in Q

Output Behavior: For input string of length n, the Mealy machine produces an output string of length exactly n, emitting outputs on the transition edges.

3. Fundamental Equivalence Theorem

A Moore machine M_moore and a Mealy machine M_mealy are defined to be equivalent if and only if for every input string w ∈ Σ*:
Output_moore(w) = λ(q₀) · Output_mealy(w)

For non-empty strings, ignoring the 1-symbol start state prefix λ(q₀), both machines produce identical output sequences at every computational step.
